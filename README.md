# M Wealth — Simulador Quantitativo Internacional

Aplicação institucional desenvolvida em Streamlit para simulação quantitativa de alocação patrimonial internacional.

A plataforma permite:

- Simulação patrimonial;
- Construção gradual de exposição internacional;
- Análise quantitativa;
- Simulação de aportes;
- Avaliação de volatilidade;
- Correlação entre ativos;
- Projeção de alocação RF vs RV.

---

# Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- yFinance
